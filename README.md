# Bank Management System

یک پروژه‌ی ساده‌ی مدیریت حساب بانکی با زبان Python که برای تمرین مفاهیم اولیه‌ی برنامه‌نویسی نوشته شده است.

## Features

- نمایش موجودی حساب
- واریز وجه
- برداشت وجه
- جلوگیری از ورود مبلغ نامعتبر
- جلوگیری از برداشت بیشتر از موجودی حساب
- منوی تعاملی برای انتخاب عملیات

## Starting Balance

The initial account balance is 1000.

## How to Run

Run the following command in your terminal:

```bash
python main.py.py
```
